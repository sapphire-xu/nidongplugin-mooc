# 泥洞插件 · MOOC 监视器 (`nidongplugin-mooc`)

适用于 [泥洞（nidong）v3.0.0+](https://github.com/sapphire-xu/nidong) 的独立中国大学 MOOC（`icourse163.org`）作业与互评监视插件。

本插件以泥洞沙箱插件形态运行，**与泥洞本体完全解耦**：账号会话 Cookie、作业缓存、评语库和运行日志均保存在本机独立目录（`%APPDATA%\edu.neu.nidong\plugins\edu.neu.plugin.mooc-monitor\`），不会上传或泄露至任何第三方服务器。

---

## 功能特性

- **课程作业 & 测验自动同步**：同时拉取中国大学 MOOC（MOOC + SPOC）在修课程的章节测验与作业，显示完整章节标题与截止时间，并支持按课程 / 完成状态 / 类型 / 互评状态 / 关键词筛选及一键跳转浏览器查看。
- **指针式 DDL 日程联动**：自动将未完成且未截止的作业以红色指针式 DDL 写入泥洞「日程」周视图（不挤占课程/日程块宽度，完成后自动清理）。
- **悬浮岛提醒**：发现新增未交作业时自动弹出泥洞顶岛提示，并在工具箱瓷贴上展示实时角标。
- **自动满分互评 & 自评**：
  - 精确识别 6 种互评阶段：**提交阶段** / **待互评** / **已互评 x/x** / **已完成** / **已过期** / **无互评**。
  - 自动处理 MOOC 的逐份解锁机制与已解锁未提交答卷，按课程要求份数（如 5 份）逐份提交全满分，并可选同步完成「自评作业」。
  - 内置**自定义评语库**，支持多行自定义评语及「随机抽取 / 顺序轮换」模式。
- **独立认证与完整日志**：支持弹窗自动填表登录或手动粘贴 Cookie；提供本地持久化日志与一键打开完整日志文件按钮；支持深浅色主题与窄窗口自适应卡片排版。

## 安装方式

需要 **泥洞 v3.0.0 或更高版本**。

### 方式一：直接下载 Release 插件包（推荐）
1. 前往本仓库的 [Releases](https://github.com/sapphire-xu/nidongplugin-mooc/releases) 下载最新版 `mooc-monitor-v*.ndplugin`（单文件包）或 `mooc-monitor-v*.zip`。
2. 打开泥洞 → 左侧 **工具箱** → 右上角 **插件管理**。
3. 点击 **安装插件**，选择刚刚下载的 `.ndplugin` 或 `.zip` 文件即可完成安装。

### 方式二：从源码文件夹安装
1. 克隆本仓库：
   ```bash
   git clone https://github.com/sapphire-xu/nidongplugin-mooc.git
   ```
2. 打开泥洞 → **工具箱 → 插件管理 → 从文件夹安装**，选中仓库根目录（包含 `plugin.json`）即可。

## 自行打包分发

在仓库根目录运行 PowerShell：

```powershell
.\pack.ps1
```

会在 `dist/` 目录下生成可直接分发的 `.zip` 和 `.ndplugin` 插件包。

## 权限说明

在 `plugin.json` 中仅声明了运行所需的最小权限：

| 权限 | 用途 |
| --- | --- |
| `agenda:write` | 将未完成作业的截止时间写入 / 清理泥洞本机日程表（`plg:` 前缀 DDL） |
| `island:notify` | 发现新未交作业或执行测试提醒时向泥洞悬浮岛发送短提示 / 提醒 |
| `http:*.icourse163.org` | 直连中国大学 MOOC 接口拉取课程、作业、互评数据，以及打开认证窗与跳转浏览器查看作业 |
